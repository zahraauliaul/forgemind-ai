
# ForgeMind AI

## Manufacturing Knowledge & Operations Intelligence Assistant

ForgeMind AI is a local-first AI assistant that connects
manufacturing documentation and operational data through
RAG, semantic search, PostgreSQL, and MCP-powered tools.

## Project Status

🚧 Early Development

The project is currently in the foundation/setup phase.

## Current Capabilities

- FastAPI application
- Health check endpoint
- Environment-based configuration
- Basic logging
- Automated testing

## Planned Capabilities

- RAG
- Semantic search
- Local LLM inference
- PostgreSQL operational data access
- MCP tools
- AI evaluation
- Retrieval optimization
- Fine-tuning experiments
